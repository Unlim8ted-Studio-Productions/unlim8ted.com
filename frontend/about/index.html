About Unlim8ted

We make films, games, music, and tools. Sometimes a story needs a soundtrack. Sometimes building the story means writing the tool first. That is how these projects end up sharing a home.

Start with something we made

The Life of a Meatball and The Glitch sit beside TimeCat, a platformer about a cat and a very inconvenient time button. The music library collects soundtracks and other audio experiments.

Tools come from problems

Our software projects include a Blender keyframe-copying add-on and a visual editor for FTL mods. Unlim8ted Phone takes that curiosity into hardware: a custom handheld, an operating-system experiment, and a lot of work still ahead.

Show the work, including the rough edges

A prototype is useful even when it is unfinished. We want project pages to say what you can try today, what needs work, and what is only an idea. Square Pixels is still a work in progress; its roadmap is not a list of features you should expect in a download.
