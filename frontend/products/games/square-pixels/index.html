Square Pixels

A pixel sandbox in development, inspired by Terraria. Explore the current build notes and the work still ahead.

Get Started See Screenshots GitHub Repo Support

Introduction

Square Pixels is an unfinished pixel sandbox. Exploration, building, and survival are the direction of the project; the status below describes what the current checklist supports.

Development status

In development This is an unfinished sandbox project. Check the notes for the build you download.

Implemented in the project checklist

Darkness and a map for unexplored areas.

Still being worked on

Collision handling, pause and settings screens, world options, saving and loading, chunk loading, inventory integration, and crafting.

Planned

Tools, multiplayer, friending, and the broader exploration and survival systems. These are goals, not a promise of features in the current build.

Getting Started

  1. Clone the repository:

    git clone https://github.com/Unlim8ted-Studio-Productions/Square-Pixels.git

  2. Install dependencies:

    pip install pygame pillow pymovie pyperclip playfab captcha astor

  3. Launch the game script or executable.

Check the releases page for available builds and their platform requirements. For help with builds, contact support@unlim8ted.com.

How to Play

Controls:

  • Move with WASD or arrow keys.
  • Open inventory with E.
  • Right-click in inventory to create an item.
  • Left-click to place an item in a slot.
  • Left-click on blocks to destroy them.

Objective:

Build behavior can change while development continues. Refer to the current build notes before trying inventory or crafting controls.
