Square Pixels: what the roadmap actually says

The current project checklist marks unexplored-area darkness and a map as implemented. Collision fixes, saving and loading, crafting, tools, and multiplayer still appear in the unfinished work. That matters: a screenshot can show the direction of a game without proving that every system works.

We have updated the page to separate that checklist from the game's intended scope. If you try a build, check its release notes and expect rough edges.
